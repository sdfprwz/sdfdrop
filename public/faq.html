FAQ

Fixes that actually work. Still stuck? Open the app and check the Help dialog diagnostics.

Same WiFi, but devices can't see each other?

Use the exact same WiFi name on both (2.4 vs 5 GHz can isolate), turn VPNs off, disable hotel-style client isolation if present. Compare the /debug key hashes on both devices — a shared hash means auto-discovery will work. Otherwise just join the same room code: it always works.

Is it really free? Any limits?

Yes — free, no accounts. P2P has no practical cap; server-relayed files cap at 100MB, text at 8KB, rooms at 100 members.

Do my files get uploaded anywhere?

No. Files travel directly between browsers over an encrypted channel. The server only swaps connection handshakes — and relays chunks without storing them if P2P fails.

Room code mismatch?

Both banners must show the identical code and headcount. The sender's toast tells the truth: “Broadcasting to 0” means nobody else is in the room yet.

Nothing arrives after Send to room?

Students must tap Accept first, then the teacher taps Send now (or waits for the 45s auto-send). Use Resend for late accepters.

Does it work on phones?

Yes — responsive from phone to desktop, installable as a PWA. Keep the tab in the foreground and the screen on during big transfers.

Layout looks broken on my phone?

Hard-refresh to drop the cached stylesheet (reload twice on mobile). The service worker uses network-first navigation so updates apply.

First load on Render is slow?

The free tier sleeps when idle — the first load after sleep takes ~30s, then it reconnects by itself.
