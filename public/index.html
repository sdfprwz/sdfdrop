FAQ

Is it really free? Any limits?

Yes — free, no accounts. Peer-to-peer has no real size cap; server-relayed transfers cap at 100MB per file.

Do my files get uploaded anywhere?

No. Files travel directly between browsers (DTLS encrypted). The server only exchanges connection handshakes and, if P2P fails, relays encrypted-in-transit chunks without storing them.

Same WiFi but devices don't see each other?

Use the same WiFi name (2.4 vs 5 GHz can isolate), turn VPNs off — or just join the same room code, which always works.

Does it work on phones?

Yes — it's a responsive web app that installs like a native app (Add to Home Screen). Keep the tab in the foreground during big transfers.

What is room broadcast?

A teacher creates a room, students join it, and one upload fans out to everyone in the room — built for classrooms sharing notes.
