Self-host in minutes

  1. 1
    Run locally

    npm install, npm start, open http://localhost:3000. Same-WiFi sharing works out of the box.

  2. 2
    Deploy on Render

    New Web Service from the repo. Build: npm install. Start: npm start. Health check: /health. Same code serves frontend and signaling.

  3. 3
    Bring your own TURN (optional)

    Defaults use Google STUN plus OpenRelay TURN. Override with TURN_URLS, TURN_USER and TURN_PASS environment variables.

Trust model

What does the server see?

Peer names, room codes and WebRTC handshake data — plus relayed chunks when P2P fails. It never stores files and has no database or accounts.

When is it truly end-to-end encrypted?

On the direct P2P path (DTLS), if you trust the signaling server that introduced the peers. Self-host for sensitive files; don't trade secrets over random public instances.

How is abuse handled?

Same-origin WebSocket policy, per-IP connection caps, message rate limits, 100MB relay cap, header-before-chunks sessions with sequence checks, and minimal security headers with no third-party scripts.
